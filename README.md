## 🚀 Featured Projects

### 1. Scientific Machine Learning for Parametric PDEs

**Neural Networks vs Polynomial Surrogate Models**

A scientific computing project investigating the accuracy and computational efficiency of neural networks and polynomial surrogate models for parametric elliptic partial differential equations.

The project combines **Numerical Analysis, Constructive Approximation, PyTorch, Machine Learning, and Scientific Computing**.

**Main activities:**
- Implemented and verified a conservative finite-difference solver for parametric elliptic PDEs.
- Generated numerical datasets for training, validation, and testing.
- Developed and trained a fully connected neural network using PyTorch.
- Constructed polynomial surrogate models using regularized least squares.
- Evaluated approximation quality in relative L2 and energy norms.
- Investigated polynomial convergence with respect to degree and training sample size.
- Verified first-order energy-norm and second-order discrete L2 convergence of the spatial discretization.
- Benchmarked numerical solvers and surrogate models across different batch sizes.

**Key results:**
- Achieved a mean relative L2 test error of **1.72 × 10⁻⁶** with a degree-6 polynomial surrogate.
- Reduced mean relative L2 error by approximately **133×** compared with the tested neural network.
- Reduced mean relative energy error by approximately **3,046×**.
- Achieved up to **72.45× faster batch inference** compared with the traditional numerical solver in controlled CPU experiments.
- Observed rapid polynomial approximation convergence for the considered smooth parameter-to-solution map.

**Technologies:** Python, PyTorch, NumPy, SciPy, scikit-learn, pandas, Matplotlib

**Main takeaway:** Classical approximation methods can provide highly accurate and computationally efficient alternatives to neural networks for smooth, low-dimensional parametric problems.
